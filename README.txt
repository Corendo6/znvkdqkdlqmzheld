쿠팡 관리 프로그램 v0.4.13

일일 매출 API 기준 판매량 (v0.4.13)
- 로켓그로스 재고 화면의 어제·7일·30일 판매량을 일일 매출 API의 판매수량으로 통일했습니다.
  한국시간 어제까지의 1일/7일/30일이며, 옵션 ID별 판매 개수를 합산합니다.
  재고 API의 30일 판매량이나 직접 입력·Excel 매출은 섞지 않습니다.
- 데이터·설정 > API 갱신·로그 > 로켓그로스 일일 매출만 > 최근 30일 > API 갱신 실행.
  기본 조회 기간도 최근 30일입니다. 전체 갱신에도 같은 기간을 적용합니다.
- 기간 전체를 성공적으로 조회하면 판매가 없는 옵션은 0개로 표시합니다.
  조회하지 않은 날짜가 있으면 해당 기간의 수량은 —입니다. 조회 완료 일수도 표시합니다.
  매출 API 조회 실패 시 이전 자료와 조회 완료 기록을 유지합니다.
- 30일 판매량에 따른 소진 예상·입고권장·판매량 정렬도 같은 수량을 사용합니다.
- 주문 API는 출고된 주문을 결제일 기준으로 집계합니다. 재조회로 늦은 출고분을 보충합니다.
  취소·반품을 차감한 순매출 또는 WING 실시간 수치와는 다를 수 있습니다.
- 그로스 마진 수정창의 쿠팡 사이즈 정보 붙여넣기도 포함합니다.
  예: 극소형 - 182*311*49(mm), 455g → 극소형 선택 후 저장.

그로스 마진 수정 · 메모리 상품 표시 정리 (v0.4.12)
- 그로스 마진의 옵션 행을 더블클릭하면 '그로스 마진 수정' 창이 열립니다.
  Enter, 선택 수정 버튼, 우클릭의 원가·사이즈 수정으로도 열 수 있습니다.
- 원가와 사이즈형을 한 창에서 수정하고 저장하면 마진을 다시 계산합니다.
  같은 모델의 모든 로켓그로스 옵션에 적용됩니다.
  원가 빈칸·사이즈 미지정은 기존 값을 유지합니다. 취소·Esc는 저장하지 않습니다.
- 현재 판매가는 상품정보에서 가져옵니다. 수정창은 판매가를 바꾸지 않으며 API/PUT 요청을 하지 않습니다.
- 쿠팡 상품 링크는 우클릭 > 쿠팡에서 상품 열기로 따로 열 수 있습니다.
- '멀티탭 관련 상품만 표시' 설정을 그로스 마진 일괄 현황에도 적용했습니다.
  기본값은 켜짐입니다. C50 등 샌디스크 메모리는 목록·검색·요약 집계에서 제외됩니다.
  USB 충전 멀티탭과, 상품명이 비어 있어도 같은 모델·등록상품으로 연결된 멀티탭 옵션은 유지합니다.
  이 설정은 데이터·설정 > 파일·표시 설정에서 바꿀 수 있으며 상품·매출 기록은 보존합니다.

- 모델 마스터와 풀필먼트 요금을 '마스터 데이터'로 통합했습니다.

- 모델 표와 미매칭 옵션 표 사이 구분선을 끌어 높이를 조절할 수 있습니다.
- 마진 계산에 사용하는 원가·요금표와 기존 상품·매출 데이터는 그대로 유지합니다.

로켓그로스 현재 판매가 마진 · F5 검색 (v0.4.10)
- 상품 관리와 로켓그로스의 상단 검색 입력칸을 제거했습니다.
  F5 또는 'F5 검색'으로 검색하고, 적용된 검색어 옆 '검색 해제'로 초기화합니다.
  배송·판매상태·재고상태 등 다른 필터는 유지됩니다.
- 로켓그로스의 행 높이를 176 → 132로 줄이고 얇은 구분선으로 정리했습니다.
  재고·판매량·현재 판매가와 함께 원가·물류비·개당 예상 마진·마진율을 표시합니다.
- 별도 가격 입력 없이 현재 판매가 기준의 개당 예상 마진·마진율을 바로 표시합니다.
  데이터·설정에서 상품정보 API 갱신 후 저장된 판매가가 바뀌면 마진도 다시 계산합니다.
- 판매가·마진 또는 '마진 상세'를 클릭하면 현재 판매가·원가·수수료·물류비를 확인합니다.
  키보드: 행에서 Ctrl+Enter는 마진 상세, Enter는 입고중 수량 관리입니다.
  마진 상세는 읽기 전용이며 가격 입력칸이 없습니다.
- 계산식은 기존 '그로스 마진'과 공유합니다.
  정산가 = 판매가 × (1 − 수수료율 × 1.1 / 100), 원 단위 반올림.
  예상 마진 = 정산가 − 원가 − (입출고비 + 배송비) × 1.1.
  마진율 = 예상 마진 / 판매가 × 100.
  보관비·반품비·쿠폰 비용 등은 포함하지 않은 예상값입니다.
- 원가는 그로스 마진의 직접 입력 원가를 우선하고, 기존 마진표 원가를 보조로 사용합니다.
  공급가에서 원가를 추정하지 않습니다. 원가·사이즈·요금이 없으면 —와 사유를 표시합니다.
  현재 판매가가 없으면 과거 엑셀 판매가를 재고 화면의 현재 가격으로 대신하지 않습니다.
- '적자 상품', '마진 미확인' 필터와 '마진 낮은 순' 정렬을 추가했습니다.
  CSV에도 원가·물류비·마진·마진율·미확인 사유를 함께 저장합니다.
- 상품 관리의 로켓그로스 숨김 설정, F5 검색, 데이터·설정의 API 갱신을 유지합니다.

- 기본 WING 보기: 상품 제목으로 묶고 옵션 / 모델을 두 줄로 보여줍니다.
- 행마다 얇은 가로선, 가격·재고와 상세정보 구역 사이에만 세로선을 표시합니다.
- 판매중지·품절 등 상태 칸에만 색을 주며 금액과 재고는 오른쪽으로 정렬합니다.
- 반복 ID는 상세 보기로 옮겼습니다. 더블클릭 또는 Enter로 상세 창을 열 수 있습니다.
- 상세 창에서 등록상품/노출상품/옵션/업체옵션 ID, 조회 시각·오류·비고를 확인합니다.
  각 값을 선택해 Ctrl+C로 복사하거나 '전체 정보 복사'를 사용할 수 있습니다.
- 우클릭 상품 열기·ID 이력·셀/행 복사, Ctrl/Shift 선택, 그룹 접기·펼치기를 지원합니다.
- 기존 전체 열 보기, 상품 편집, 검색·필터·상품 묶음별 페이지 이동도 유지합니다.
- 보이는 행만 그려 많은 옵션이 있는 상품에서도 화면 요소가 계속 늘어나지 않습니다.

상품 관리에서 로켓그로스 숨기기
1. 데이터 · 설정 > 파일 · 표시 설정 > '상품 관리에서 로켓그로스 숨기기'.
2. 상품 관리 상단의 '로켓그로스 숨기기'에서도 같은 설정을 바로 바꿀 수 있습니다.
3. 기본값은 켜짐이며, 바꾸면 즉시 저장되어 재실행 후에도 유지됩니다.
4. 상품 관리의 WING 보기 / 전체 열 보기와 검색 결과·표시 건수에만 적용됩니다.
   로켓그로스만 있는 묶음은 숨기고, 혼합 상품은 판매자배송 옵션을 표시합니다.
5. 로켓그로스 재고 현황·일일 매출·그로스 마진·API 수집·전체 상품 CSV는 그대로 유지합니다.
   상품 데이터를 삭제하거나 쿠팡에 PUT 요청을 보내지 않는 표시 옵션입니다.
6. 로켓그로스 배송 필터를 선택한 상태에서 숨기면 배송 필터를 '전체'로 되돌립니다.

실행과 갱신
1. 새 폴더에 압축을 풀고 RUN_WITH_PYTHON.cmd를 실행하세요.
2. EXE를 쓰면 BUILD_EXE.cmd로 다시 만든 뒤 dist\CoupangManager.exe를 실행하세요.
   예전 EXE에는 수정이 적용되지 않습니다. 왼쪽 아래 v0.4.13을 확인하세요.
3. 데이터 · 설정 > API 갱신 · 로그에서 API 키를 확인하세요.
4. 갱신 범위를 선택하고 API 갱신 실행을 누르세요.
   전체: 로켓그로스 재고 → 일일 매출 → 상품정보·판매상태 순서
   로켓그로스 재고만: 재고를 빠르게 다시 확인할 때
   로켓그로스 일일 매출만: 주문 내역을 기존 일일 매출에 기록할 때
   상품정보·판매상태만: 상품명·가격·판매상태를 갱신할 때
5. 다른 화면에서는 저장된 자료만 보여줍니다. 시작/주기적 자동 API 요청은 하지 않습니다.

로켓그로스 일일 매출
1. 데이터 · 설정 > API 갱신 · 로그에서 '로켓그로스 일일 매출만'을 선택합니다.
2. '전일'은 어제 하루, '최근 7일'·'최근 30일'은 어제까지의 해당 기간을 선택합니다.
   날짜 버튼은 기간만 바꿉니다. 실제 요청은 'API 갱신 실행'으로 시작합니다.
3. 기본 조회 기간은 전일까지 최근 30일입니다. 늦게 출고된 주문을 보충하려면
   같은 기간을 다시 조회하세요. 직접 지정할 때도 한 번에 최대 30일, 전일까지입니다.
4. 완료 후 일일 매출에서 날짜·옵션별 판매량, 주문 건수, 금액을 확인합니다.
   날짜 = 한국시간 결제일 / 금액 = 판매수량 × 주문 당시 단가의 합계.
   주문 건수는 해당 옵션을 포함한 서로 다른 주문 수입니다.
   여러 옵션이 같은 주문에 있으면 각 옵션에 1건씩 잡히므로 행 합계는 전체 고유 주문 수와 다를 수 있습니다.
5. 자료 출처에 '주문 API · 출고분·잠정'을 표시합니다.
   이 API는 출고된 주문만 반환합니다. 어제 결제 후 아직 출고되지 않은 주문은 나중에 잡힙니다.
   취소·반품을 자동 차감한 순매출이나 정산금액이 아니므로 WING 통계와 다를 수 있습니다.
6. 주문번호·옵션 ID를 저장해 재조회해도 중복 합산하지 않습니다.
   조회에서 빠진 주문을 취소로 간주하여 지우지 않으며, 취소·반품 차감 기능은 없습니다.
   모든 페이지를 받은 뒤 한 번에 저장하므로 중간 실패·취소 시 해당 조회의 일부만 저장하지 않습니다.
7. 같은 날짜·옵션에 이미 저장된 Excel/수기/CSV 매출이 있으면 그 기록을 우선합니다.
   API 갱신 결과의 '기존 기록 우선' 건수로 확인할 수 있습니다.
   옵션 ID 없는 기존 자료는 같은 날짜·모델 기준으로 보호하며,
   모델 미연결 API 자료는 중복 여부가 불명확하면 보수적으로 반영을 보류합니다.
   API 자료가 있는 날짜·옵션에 쿠팡 Excel을 가져오면 0매출도 반영해 API 값을 대체합니다.
8. 모델을 찾지 못한 API 자료도 일일 매출에 '모델 연결 필요'로 표시합니다.
   마스터 데이터 > 모델·옵션 매핑 > 미매칭 옵션에서 연결하면 저장된 API 매출에도 모델명이 붙습니다.
9. '선택 삭제'는 일일 매출 표시 자료를 지웁니다. 원본 주문은 보관되므로
   API를 다시 갱신하거나 모델을 연결하면 해당 매출이 다시 생성될 수 있습니다.
10. 판매자배송 주문 API는 이번 연동 대상에 포함되지 않습니다.

F5 검색창
- 프로그램에서 F5를 누르면 현재 화면의 검색창이 열립니다.
- 상품 관리 / 로켓그로스 재고 현황 / 마스터 데이터 / 그로스 마진 / 일일 매출에서 지원합니다.
- 검색어를 입력하고 Enter: 검색 적용. Esc: 변경 없이 닫기.
- 기존 검색어는 선택된 상태로 열리며, 빈칸으로 검색하면 검색어를 해제합니다.
- 배송구분·재고상태 등 기존 필터는 유지됩니다.
- 검색 기능이 없는 화면에서는 검색을 적용할 때 상품 관리로 이동합니다.
- F5로 API를 요청하지 않습니다. 입력·설정 창이 열려 있으면 해당 창을 먼저 닫으세요.

응답 확인
- 현재 작업, 응답 대기, 경과 시간이 표시됩니다.
- 작업 취소를 누르면 진행 중인 요청이 끝난 후 멈춥니다.
- 오류 사유는 같은 화면의 실행 / API 로그에서도 확인합니다.
- 재고·매출 조회가 실패하면 각각 마지막 성공 자료를 유지합니다.
- 전체 갱신 중 재고가 먼저 완료되면 재고 화면에서 확인할 수 있습니다.

재고 화면에 표시되는 상품
- 현재 판매자의 최근 성공한 로켓그로스 재고 API 응답에 있는 옵션만 표시합니다.
- 등록정보만 로켓그로스인 상품은 넣지 않습니다.
- 재고·최근 30일 판매가 모두 0이고 입력된 입고중 물량도 없으면 제외합니다.
- 최근 판매가 있는 품절 상품은 계속 표시합니다.
- 조회 전에는 빈 목록입니다. 먼저 데이터·설정에서 API를 갱신하세요.
- 실제 쿠팡 상품 페이지의 로켓 배지를 직접 조회하는 기능은 아닙니다.

값의 출처
- 판매가능 / 최근 30일 판매: 재고 API
- 어제 / 7일 판매: 옵션 ID가 연결된 로켓그로스 매출 저장 자료 (한국시간)
- 입고중: 직접 입력. 입고가 끝나면 아직 남아 있는 수량으로 수정하세요.
- 판매가: 저장된 상품정보. 쿠폰가·지도가: 마진 상세 창에서 확인
- 개당 예상 마진: 그로스 마진과 같은 원가·수수료율·현재 물류비 요금으로 계산
- CSV 예상 개당 비용: 저장 요금표의 수수료 + 입출고비 + 배송비 (부가세 포함)
- 입고권장 / 소진 예상 / 재고 상태: 자체 계산, 쿠팡 공식 추천·판정이 아닙니다.
- 없는 값을 0으로 채우지 않고 —로 표시합니다.

권장 입고량
프로그램 자체 고정 계산식으로 산정합니다. 쿠팡이 제공하는 권장량이나 AI 수요 예측은 아닙니다.
하루 평균 = 최근 30일 판매량 / 30
추가 입고량 = 하루 평균 * (입고 소요일 + 확보할 판매일수 + 여유일수)
              - 판매가능 재고 - 입고중 수량
음수는 0개, 나머지는 입고 단위로 올립니다.
기본 소요일 5일 / 확보 14일 / 여유 3일이며 입고 기준 설정에서 바꿉니다.
예: 30일 판매 300개, 재고 80개, 입고중 40개라면 10 * 22 - 80 - 40 = 100개입니다.
입고 단위가 24개라면 120개로 올립니다. 행사·계절성·품절 기간은 자동 보정하지 않습니다.
입고중 미입력, 판매량 0, 재고 미확인, 24시간 지난 재고는 추천을 보류합니다.

기존 데이터 유지
- 일반 실행: %APPDATA%\CoupangManager DB와 API 설정을 이어서 사용합니다.
- 포터블(COUPANG_MANAGER_PORTABLE=1): 종료 후 기존 userdata를 새 폴더로 복사하세요.
- 사용 중인 userdata를 패키지의 오래된 데이터로 덮어쓰지 마세요.
- 원본 상품·재고 기록을 삭제하지 않습니다.
